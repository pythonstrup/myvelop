# 문장 규칙

`src/content/blog/ko`의 한국어 본문에 적용한다. 아래 예시는 전부 실제 글에서 고친 것이다.

## 윤문할 때의 전제

- <strong>앞뒤 순서를 바꾸지 않는다.</strong> 문장의 등장 순서, 문단의 순서, 한 문장 안에서 정보가 나오는 순서를 그대로 둔 채 종결과 연결만 손본다. 순서를 바꾸면 글쓴이가 짚어둔 논리의 흐름이 무너진다.
- <strong>내용을 더하거나 빼지 않는다.</strong> 사실·수치·고유명사·인용은 한 글자도 건드리지 않는다.
- 고칠 이유가 없는 문장은 그대로 둔다. 멀쩡한 문장을 취향으로 바꾸지 않는다.

## 문장은 완결형으로 끝낸다

체언이나 부사구에서 문장을 끊지 않는다. 서술어까지 붙여 하나의 완성된 문장으로 쓴다.

| 고칠 것 | 고친 뒤 |
| --- | --- |
| 원인부터. | 원인부터 짚어보자. |
| 여기서 함정 하나. | 여기에 함정이 하나 있다. |
| 제공하는 도구는 `sequentialthinking` 하나. | …`sequentialthinking` 하나뿐이다. |
| 오히려 이득. | 오히려 이득이다. |
| 첫째, CLI가 없고 OAuth만 열려 있는 SaaS. | …열려 있는 SaaS다. |

같은 규칙이 세 곳에 더 걸린다.

- <strong>전언·인용의 꼬리</strong> — "공유하면 격리된 테스트를 못 돌린다고." → "…못 돌린다는 것이었다."
- <strong>명사 나열로 끝나는 단락</strong> — "OAuth 뒤의 SaaS, 상태를 쥔 도구, 셸이 없는 환경, 대화 속 UI." → "…대화 속 UI 넷이다."
- <strong>평서문 안의 물음표</strong> — "이 서버는 …문제가 아니라, 애초에 지금도 필요한 물건인가?" → "…필요한 물건인가 하는 생각이었다." 독자에게 직접 묻는 질문은 물음표를 그대로 두되 종결 어미를 갖춘다. "끝났나. 되나."보다 "끝난 걸까. 되는 걸까."가 낫다.

## 대시로 문장을 대신하지 않는다

`—`는 목록·정의의 라벨 뒤에서만 쓴다. 그 밖의 자리에서 대시로 두 조각을 이어붙였다면 조사나 쉼표로 푼다.

- 유지: `<strong>fixed-window의 정렬 문제</strong> — 우리 윈도우와 상대 윈도우의 시작 시각이 다르면 …`
- 고칠 것: "단계적 사고, 중간 수정, 분기 탐색 — 이 서버가 강제하던 것들을" → "…분기 탐색<strong>처럼</strong> 이 서버가 강제하던 것들을"
- 고칠 것: "…물어보는 습관 — 그게 이번에 맞바꾼 교훈이다" → "…물어보는 습관, 그게 이번에 맞바꾼 교훈이다"

## 문장을 잇는 법

- <strong>주어가 빠진 채 이어지는 문장</strong>은 주어를 세우거나 앞 문장에 연결한다. "공식 문서가 먼저 말했다. 외부 서비스와 … 쓰라고, CLI가 …명시한다." → "…먼저 말한 것이다. 외부 서비스와 … 쓰라고 <strong>권하면서</strong>, CLI가 …명시한다."
- <strong>인과로 붙는 짧은 두 문장</strong>은 하나로 잇는다. "서명에는 IAM 신원이 담겨 있다. 그래서 RDS는 …" → "서명에는 IAM 신원이 담겨 <strong>있어서</strong> RDS는 …"
- <strong>세 절 이상 나열</strong>은 쉼표로 끊어 숨을 준다. "두 번 하고 왕복이 붙고 컨텍스트를 차지한다" → "두 번 하게 되고, 왕복이 붙고, 컨텍스트를 차지한다"
- <strong>주어와 서술어 사이의 쉼표</strong>는 뺀다. "서버 대부분이, 더 싸고" → "서버 대부분이 더 싸고"
- <strong>괄호 삽입</strong>은 문장에 녹인다. "커넥션에 걸어두면(`PGOPTIONS='-c role=…'`) 파일마다" → "커넥션에 `PGOPTIONS='-c role=…'`<strong>로</strong> 걸어두면 파일마다"

## 겹구조를 풀고 우리말로 쓴다

- "~는 건 ~라는 점이다" → "흥미로운 건 이 서버는 …남는다는 점이다" → "흥미롭게도 이 서버는 …남는다"
- 번역투·영어 어휘 → "이후 생기는 전부가 자동으로 <s>커버된다</s>" → "…전부에 권한이 자동으로 붙는다"
- 은어·유행어 → "MCP 자체도 <s>다이어트 중</s>이다" → "…군살을 덜어내는 중이다" / "보안 관점의 <s>덤</s>도 있다" → "보안 관점에서 얻는 것도 있다"
- 한자어 명사구 → "나머지 메시지는 전부 <s>무수정 통과다</s>" → "…손대지 않고 그대로 흘려보낸다"

## 유지할 것

기존 글에 이미 자리잡은 습관이라 새로 쓸 때도 따른다.

- 평서 종결(`~다`)로 밀고 나가되 문장은 짧게 끊는다.
- 질문을 던지고 곧바로 답한다. "어떻게 될까? 엄청난 서버 부하가 발생할 것이다."
- 대비 구조로 요점을 박는다. "A가 아니라 B다."
- 절을 닫을 때 조건을 정리한다. "이 안이 맞는 때는 …이다."
- 강조는 `<strong>`을 쓴다. `**`는 24편 어디에도 없다. 이탤릭(`*…*`)은 이미지 캡션 전용이다.
- frontmatter `title:`의 부제 구분자는 `-`다. 본문 헤딩에서는 `—`도 쓴다(`## 장애 — 한도를 지켰는데 429가 온다`).
- 본문에 수평선(`---`)을 넣지 않는다. 절 구분은 헤딩이 한다.
